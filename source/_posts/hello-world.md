欢迎来到我的博客!这是用 Hexo 搭建的第一篇文章。

## 为什么写博客?

把学到的知识整理成文章,是最好的复习方式。以后我的 Python 学习笔记都会发布在这里。

## 如何写新文章

在博客目录下运行:

```bash
hexo new "文章标题"
```

会在 `source/_posts/` 下生成一个 Markdown 文件,用编辑器写完内容后:

```bash
hexo clean     # 清理缓存
hexo generate  # 生成静态页面
hexo server    # 本地预览,浏览器打开 http://localhost:4000
```
