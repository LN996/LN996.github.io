📖 课堂经典练习(视频例题)

1. 编程题四步法

读题 → 想思路(先写注释伪代码) → 写代码 → 测边界,视频里反复强调:先想清楚再动手。

  • 读题:把题面要求逐句圈出来,明确输入是什么、输出是什么
  • 想思路:用中文注释把步骤写下来,再逐行翻译成代码
  • 写代码:小步走,每写一小段就运行验证
  • 测边界:空输入、错误输入(如数字位置输入了字母)、极端值(0、负数)

2. 经典练习与考点对照

每个经典练习都对应固定的知识点,练一题等于复习一片。

  • 九九乘法表:双层for + end参数;斐波那契:多重赋值 a, b = b, a+b
  • 猜年龄 / 登录锁定:while循环 + break + while-else
  • 购物车 / 三级菜单:循环 + 字典/列表操作 + 标志变量
  • 字符统计:dict.get(key, 默认值);去重:in 判断 + 空列表收集
  • 素数打印:for-else 的经典应用(没被 break 才是素数)

3. 手写编程题怎么练

先自己完整写一遍,再对照参考答案,自评结果会计入错题本和正确率。

  • 不会写时先看提示,看完提示再写;直接看答案=没练
  • 写完对比参考答案:不是“结果对就行”,还要看思路是否一致、有没有更Pythonic的写法
  • 自评「没做出来」的题会进错题本,配合「温故知新」模式过几天再练一遍

📖 课后作业（Python基础）

1. 作业清单与完成顺序

基础阶段的作业按天布置：文件作业(Day12) → 函数/装饰器作业(Day16~20) → 模块作业(Day21) → 并发作业(Day41)，完成顺序就是复习顺序。

  • Day12 文件作业：登录注册程序（文件存用户、写日志）→ 对应本站「文件操作」章
  • Day16~20 函数作业：装饰器计时器、生成器读大文件 → 对应「函数」章
  • Day21 模块作业：按目录规范拆分程序 → 对应「模块与常用模块」章
  • Day41 并发作业：线程/进程/协程三种方式实现同一段逻辑 → 对应「并发编程」章
  • 做完到「题库练习」搜对应章节的题自测，错题进错题本
